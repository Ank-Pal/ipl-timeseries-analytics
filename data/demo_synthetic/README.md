# Synthetic Calibration Datasets (Archived)

> [!WARNING]
> The CSV files in this directory (`matches.csv` and `deliveries_summary.csv`) are simulated/synthetic calibration datasets generated during early pipeline prototyping.
> 
> **They do not represent real historical IPL match scorecards.**
> 
> All production analytics, SQL warehouse models, and statistical time-series models now run directly on the authentic **CricSheet** ball-by-ball dataset (`data/processed/ipl_master.db`).
